# Практическая работа 3.2.49 — Защита файлов WordPress

Дата: 17.11.2026

Комплект включает Apache-правила для корня и uploads, пример директив wp-config.php без секретов, read-only аудит Bash/PHP, инструкцию внедрения, матрицу 100 баллов и учебную страницу.

Важно: GitHub не является сервером WordPress. HTTP 403, CHMOD, интерфейс wp-admin и вынос настоящего wp-config.php требуют работающей установки CMS и доступа к хостингу. Не публикуйте настоящий wp-config.php, пароли, salts или дампы БД.

Для запуска аудита: bash scripts/audit-wordpress.sh /path/to/wordpress
